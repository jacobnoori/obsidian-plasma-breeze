# Plasma Breeze for Obsidian

An Obsidian theme that matches KDE Plasma's **Breeze** colour scheme, so Obsidian sits naturally next to Dolphin, Firefox and the rest of your Plasma desktop.

| Area | Breeze role | Light | Dark |
| --- | --- | --- | --- |
| Top bar (tab headers across both sidebars and the main pane) | Title bar | `#475057` | `#2a2e32` |
| Left/right sidebars, ribbon, status bar | Window background | `#eff0f1` | `#202326` |
| Main content | View background | `#fcfcfc` | `#141618` |
| Accent / focus | Highlight | `#3daee9` | `#3daee9` |
| Selected file | Dolphin selection | `#c2e0f5` | `#1f4a62` |

Fonts default to **Noto Sans** and **Hack** (Plasma's defaults) when installed.

## Install manually

1. Copy `manifest.json` and `theme.css` into `<your vault>/.obsidian/themes/Plasma Breeze/`.
2. In Obsidian open **Settings → Appearance → Themes** and pick **Plasma Breeze**.

For the closest match to Plasma, set **Settings → Appearance → Window frame style** to **Hidden** so the dark tab strip becomes the window's title bar.
